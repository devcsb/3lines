### 3Lines

하루를 **감사 / 수용 / 의도** 세 줄로 기록하는 미니멀 저널 앱입니다.

**기술 스택:**
- Flutter 3.41 / Dart 3.11
- 상태관리: Riverpod + code generation
- 로컬 DB: Drift (SQLite)
- 차트: fl_chart
- 알림: flutter_local_notifications
- 인증: local_auth (생체인증)

**주요 기능:**
- GitHub 잔디 스타일 히트맵 (스크린샷 참고 — 이거 만드는 게 제일 재밌었습니다)
- 감정 추이 차트 + 요일별 패턴 분석
- 키워드 빈도 분석 (한국어 조사 분리 처리 포함)
- JSON export/import
- 생체인증 잠금
- 100% 오프라인 — 서버 없음, 계정 없음

**설계 원칙:**
- 프라이버시 퍼스트: 네트워크 퍼미션조차 없음
- 30초 룰: 핵심 플로우가 30초를 넘지 않을 것
- 비처벌적 UX: 기록 공백에도 "자리를 비웠어도 괜찮아요" 같은 격려 메시지

### 개발하면서 재미있었던 점

1. **히트맵 렌더링**: CustomPainter로 셀 크기를 화면 너비에 동적 계산하는 로직
2. **한국어 키워드 분석**: 조사 분리가 생각보다 까다로움 (은/는/이/가/을/를 등)
3. **Drift 마이그레이션**: 사진 첨부 기능 추가할 때 DB 스키마 v2 마이그레이션
4. **스트릭 유예일(Grace Day)**: Duolingo에서 영감받은 1일 유예 시스템

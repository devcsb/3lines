# 감정만 기록하기와 책갈피 구현 계획

[설계와 경쟁 기능 근거](../specs/2026-11-06-gentle-features-design.md)를 따른다. 구현은 현재 세션에서 진행하고, 설계와 최종 변경은 읽기 전용 검토를 받는다. 기존 미커밋 UI/아이콘/알림 변경을 보존한다.

- [x] 감정만 기록하기: TodayState 저장 조건, 버튼 문구, Today/상세 빈 답변 표시를 변경한다. 감정만 저장→수정→한 행 유지, 기존 회고와 JSON 호환을 테스트한다.
- [x] 책갈피 저장: Entries boolean과 schemaVersion3, DailyEntry 필드/JSON, EntryRepository의 단일 필드 업데이트와 스트림을 구현하고 Drift 코드를 생성한다. v1/v2 업그레이드, 타임스탬프 유지, 수정/삭제/백업을 테스트한다.
- [x] 책갈피 UI: 재사용 BookmarkButton, 모아보기 화면과 route, 타임라인 진입, Today/상세의 버튼을 연결한다. DB 스트림으로 갱신하되 Today의 작성 상태를 invalidate하지 않는다.
- [x] 전체 흐름: 감정만 기록한 오늘/오래된 기록 책갈피 추가→모아보기→해제, 실패 후 재시도와 빠른 중복 탭, 320px/200% 레이아웃을 검증한다.
- [x] 최종 검토, 전체 Flutter 테스트, 정적 분석, 변경 파일 포맷, diff 검사와 실제 위젯 렌더링을 완료하고 결과를 남긴다.

세부 구현 선택은 기존 Riverpod provider와 Drift stream을 재사용한다. 별도 네트워크, 로그 수집, 작업 큐, 다중 모드 인터페이스는 추가하지 않는다. 데이터베이스 업그레이드는 테스트 DB에서만 실행하고 배포는 하지 않는다.

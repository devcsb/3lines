# 감정만 기록하기와 책갈피 구현 결과

2026-11-06. [경쟁 기능 조사와 설계](../specs/2026-11-06-gentle-features-design.md), [구현 계획](../plans/2026-11-06-gentle-features.md).

## 반영한 기능

- 감정만 골라도 ‘마음만 남기기’로 명시적으로 저장한다. 같은 날 수정하기로 글을 더해도 한 개의 기록을 유지한다. 감정만 기록한 날은 Today와 상세에 빈 답변 카드 세 개를 표시하지 않는다.
- Today의 저장된 기록과 타임라인 상세에서 책갈피를 추가/해제한다. 타임라인의 ‘책갈피 모아보기’에서 모든 날짜를 최신순으로 다시 연다. 최근 12주에 기록이 없어도 접근할 수 있다.
- 책갈피는 기록의 내용과 작성 시각을 바꾸지 않는다. 일반 수정 후에도 유지하고, 작성 중인 Today를 초기화하지 않는다. 처리 중 중복 탭을 막으며 실패 시 현재 표시를 유지하고 재시도를 안내한다.
- schemaVersion 3과 `is_bookmarked`를 추가했다. 기존 v1/v2 DB에서 기록과 사진을 유지한다. 새 백업에는 책갈피를 담고, 이전 백업을 가져올 때 기존 책갈피를 유지한다.
- 상세 화면의 중복 드래그 손잡이를 제거하고 Q&A 텍스트를 테마의 본문 색상으로 조정했다. 밝은/어두운 테마에서 질문과 답변을 더 또렷하게 읽을 수 있다.

## 검증 결과

| 검증 | 결과 |
|---|---|
| `dart run build_runner build` | 성공. Drift 생성 코드 반영 |
| `flutter test --reporter expanded` | **454개 통과**, 종료 코드 0 |
| `flutter analyze --no-pub` | **No issues found**, 종료 코드 0 |
| 변경 Dart 파일 포맷, `git diff --check` | 통과 |
| 실제 위젯 트리 렌더링 | 390×844, 밝은/어두운 테마 2개 테스트 통과. 아래 PNG 생성 |
| 별도 읽기 전용 설계/구현 검토 | 과거 기록에서 수정 가능하다고 안내하지 않도록 설계 수정. 최종 구현과 시각 보완에서 추가 지적 없음 |

새 테스트는 v1/v2 마이그레이션, 감정만 저장 후 글 추가, JSON 왕복과 이전 백업, 명시적 해제, 잘못된 필드 타입, 수정 시 책갈피 유지, 검색 결과, 날짜 정렬, 삭제, 스트림 갱신을 다룬다. 실제 앱 경로에서는 오래된 책갈피를 해제하고 돌아와도 오늘 초안이 남는지 확인했다. 버튼 실패 후 재시도와 중복 탭, 320px 화면에서 200% 글자로 목록/상세/빈 상태를 읽는 경우도 통과했다.

검증 중 수동 생성한 검색 결과 모델의 새 필드 누락을 수정했다. 기존 상세 테스트는 빈 답변 정책 변경에 맞게 조정했고, Drift 스트림 해제 후 예약된 타이머를 테스트 안에서 처리하도록 정리했다. 한국어 환경의 뒤로 가기 테스트는 영어 툴팁을 가정하지 않도록 바꿨다.

## 검증 범위

실기기 TalkBack/VoiceOver, 실제 사용자 만족도와 정서적 효과, 스토어 배포는 검증하지 않았다. DB 업그레이드는 테스트 DB에서만 실행했다. 자동 초안은 날짜 변경과 사진 수명, 수정 취소와 중단 복구 정책이 함께 필요해 별도 후보로 남겼다. 기존 아이콘/알림 등 다른 작업 변경은 보존했다.
